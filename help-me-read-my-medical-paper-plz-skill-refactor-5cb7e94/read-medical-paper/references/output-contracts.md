# Output Templates

## Purpose

Use these response structures to preserve rigor while matching the user's requested depth.

## When To Use

Use when the user asks for a specific output format or when a structured answer improves clarity.

## Core Checklist

### Whole-Paper Analysis

Optionally open with `paper at a glance` and a one- or two-sentence independent-audit verdict.

1. Reference-derived knowledge base
2. Plain-language overview
3. Research question
4. Background concepts
5. Study design and evidence level
6. Main claims
7. Figure/table analysis
8. Independent Evidence Audit
9. Methods/statistics
10. Strengths
11. Limitations
12. Significance
13. Uncertainties

### Reference-Derived Knowledge Base

Select only the load-bearing references. Show: reference and role, direct finding, how the current paper uses it, inherited versus new, transfer risk or contradiction, and verification/status. End with four lines: established before, inherited/reused, newly demonstrated, and still unsupported.

### Figure- And Table-By-Table Analysis

For each main figure:

`purpose and intended claim -> canonical integrated panel table from figures-and-tables.md -> figure verdict`

Use one row per labeled panel, or an inseparable panel group, with an accessible crop or explicit unavailable marker. Keep the located legend paraphrase, located corresponding article-text paraphrase, and independent analysis in that row. Add a brief quote or shared-quote reference for load-bearing passages when useful and permitted. Report material supplementary dependencies beside the verdict; add supplementary-panel rows only when directly analyzed or requested exhaustively.

For an article table, use the separate claim-bearing row/result-block schema in [figures-and-tables.md](figures-and-tables.md); do not invent a panel image requirement.

### Independent Evidence Audit

Use the canonical claim-to-data matrix in [core-principles.md](core-principles.md). Put the decisive assumption, alternative explanation, or redundant-evidence problem in `weakest link`; add the most efficient follow-up experiment or analysis in prose only when it helps answer the user's request.

### Loopholes And Redundancies

For a focused alternative to the full Independent Evidence Audit: repeated evidence, genuinely new information, key remaining uncertainty, and one better experiment or analysis that would close the loophole. Do not add this as a duplicate section after the full audit.

### Clinical-Trial Appraisal

PICO, phase and design, assignment method, comparator type, dose/escalation, concealment/blinding when relevant, endpoints, power, stopping rules, protocol/SAP deviations, analysis set, missing data, effect size, harms, subgroups, historical/natural-history limitations, clinical significance, conflicts, bottom line.

### Mechanistic-Paper Appraisal

Claim, model, perturbation, controls, rescue, orthogonal validation, replication, quantification, causal chain, alternative explanations, translational relevance.

### Systematic-Review Appraisal

Question, search, eligibility, included studies, risk of bias, synthesis method, heterogeneity, publication bias, certainty, bottom line.

### Diagnostic/Prognostic Appraisal

Question, target population, index test/model, reference standard or outcome, timing, missing data, sensitivity/specificity or discrimination, calibration, PPV/NPV or risk thresholds, validation cohort, bias risks, clinical utility, bottom line.

### Journal Club Prep

One-sentence takeaway, why it matters, key figures, strongest claim, weakest claim, loopholes and redundancies, more defensible conclusion, methods to explain, likely questions, discussion prompts.

### Explain From First Principles

Basic concept, analogy if helpful, vocabulary, mechanism, how the paper tests it, what the data show, what remains unclear.

### Reference Or Citation Check

Claim to verify, best source to check, identifier available, what the source confirms, retraction/preprint/status concerns, contradiction check, and what cannot be verified.

### Power Or Precision Check

Endpoint, planned analysis, stated sample size/power basis, effect size basis, CI/MDE interpretation, multiplicity/dropout/clustering concerns, and what the result can or cannot rule out.

## Common Pitfalls

- Filling every template section when the user requested a focused answer.
- Outside mandatory integrated figure analysis, using a table when prose would be clearer.
- Hiding uncertainty in a tidy format.
- Filling a claim-to-data matrix with invented figure details when the paper content is unavailable.
- Claiming that citations or current literature were checked when no lookup source was available.

## Minimal Example

Synthetic bottom line: "The strongest support is Figure 3's rescue experiment; the weakest link is whether the cell-line model generalizes to patients."
