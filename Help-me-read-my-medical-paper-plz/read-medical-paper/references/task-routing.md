# Task Routing

Select only the references needed for the user's request. Apply [core-principles.md](core-principles.md) to every route.

## Choose A Route

| User task | Read and apply |
|---|---|
| Whole paper, journal club, or "what does this paper really show?" | [whole-paper-workflow.md](whole-paper-workflow.md), [reference-tracing.md](reference-tracing.md), [figures-and-tables.md](figures-and-tables.md), and [quality-and-failure-checks.md](quality-and-failure-checks.md) |
| Abstract only | [output-contracts.md](output-contracts.md); label all conclusions provisional because Methods, full Results, figures, tables, and supplements are unavailable |
| One figure, table, or panel | [figures-and-tables.md](figures-and-tables.md); add [methods-and-statistics.md](methods-and-statistics.md) when interpreting a plotted estimate or test |
| Method, statistic, or power question | [methods-and-statistics.md](methods-and-statistics.md); add [figures-and-tables.md](figures-and-tables.md) if the result is plotted |
| Reference, novelty, or citation check | [reference-tracing.md](reference-tracing.md) |
| Unknown or mixed study design | [study-design-routing.md](study-design-routing.md), then the applicable design reference |
| Interventional clinical study | [clinical-trials.md](clinical-trials.md) |
| Cohort, case-control, cross-sectional, or nonrandom comparison | [observational-studies.md](observational-studies.md) |
| Systematic review or meta-analysis | [systematic-reviews-and-meta-analysis.md](systematic-reviews-and-meta-analysis.md) |
| Basic-science or mechanistic study | [mechanistic-studies.md](mechanistic-studies.md) |
| Requested response format | [output-contracts.md](output-contracts.md) |
| Final answer audit | [quality-and-failure-checks.md](quality-and-failure-checks.md) |

Routes may stack. For example, analyze a nonrandomized intervention with both clinical-trial and observational-confounding checks. Analyze a diagnostic model developed from an observational cohort with both diagnostic/prognostic and observational checks from [study-design-routing.md](study-design-routing.md).

Do not load an unrelated design reference merely because it is available. Do not consult a worked example unless a concrete formatting or depth decision requires it.
